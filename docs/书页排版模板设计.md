# 教程书页面排版模板设计

> 定位：天工开物 mod 教程书（Modonomicon，当前《乃粒》卷）的**通用页面模板规范**——每一条目按固定页面串排版（条目划分**不与原书每节一一对应**，按内容好写、好读来分；见 §7 口径），让书同时具备"古籍原典""白话知识""实物图鉴/索引"三种功能。
> 状态：**设计定稿（2026-09-08 用户拍板）**；落地执行排在乃粒玩法实物（#33/#34/#35 与核心加工链）之后，避免链接目标不存在造成返工。
> 相关：docs/乃粒篇大纲.md（内容蓝图）、docs/乃粒稻作玩法设计.md（玩法机制）。

---

## 1. 核心理念

1. **原文是玩法本体**：文言原文 = 内容数据，任何语言玩家读到同一份（与翰墨台题库 wenyan 同口径），不随语言翻译。
2. **白话是译注**：正文白话 = 原文章节的意译讲解，走 lang 三语。
3. **知识可点可查**：译文/档案中提到的 mod 元素（物品/方块/机制），能点击跳到**书内介绍它的那一页**；核心加工链在书内直接可见，杂项合成靠 JEI 点击兜底。

## 2. 页面串总览（每条目一套）

> **条目划分口径（2026-09-20 用户拍板）**：**不追求与原书每节 1:1 对齐**——怎么写得舒服就怎么分。
> 一节可拆、相邻短节可并、原书没有的导览/机制段落也可立条目。原文页只照录该条目**实际讲到的**那部分，不必强求整节全录。

```
┌ 文言原文页（1~N，内容数据）─────────────────┐
│  题记式排版：条目名在上，居中文言原文，        │
│  页脚注出处《天工开物·乃粒》                   │
└──────────────────────────────────────────────┘
┌ 白话译文页（1~M，lang 三语）─────────────────┐
│  原文的意译讲解；文中出现的 mod 元素名词       │
│  挂【内链】→ 跳到对应档案介绍页                │
│  （现有 3 页白话正文 = 译文段，直接沿用）       │
└──────────────────────────────────────────────┘
┌ 本节涉及 · 档案段（每元素 1 页）──────────────┐
│  spotlight 页：物品/方块大图标 + 名字          │
│  + 档案介绍文字（这是什么、书里怎么用）        │
│  （机制类无实体物 → text 页写清对应玩法）      │
└──────────────────────────────────────────────┘
┌ 核心加工链合成页（≤1~2 页/节）────────────────┐
│  crafting（或 smelting/processing）页，        │
│  只放"本条教的就是这个"的链（例：脱粒          │
│  稻谷→米；未来舂米）。杂项合成一律不收录，      │
│  靠 JEI 点击兜底。                             │
└──────────────────────────────────────────────┘
```

**页数不定长**：视该节内容多少增减档案段数量；纯知识节（无新实物）可以没有档案段。

## 3. 逐条规范

### 3.1 文言原文页（内容数据）
- **来源**：**公版全文本地存档**——`docs/天工开物·乃粒原文.md`、`docs/天工开物·粹精原文.md`（繁体照录 + 校勘注）。~~复用题库 wenyan~~ **已推翻（2026-09-19）**：题库每条仅 3 句，撑不起整节原文。
- **字形口径（2026-09-19 用户拍板）**：书页展示**用简体**（存档保留繁体）；只做繁→简，不改字、不节略。
- **实现方式（2026-09-20 反编译确认，选 a 方案）**：页 `text` **直接写字面量**。依据：`BookTextHolder` 无 component 时 `getString()` 走 `I18n.get(str)`，查不到键就**原样返回** → 三语天然显示同一份原文，**不必三语各存一份**。
  - ⚠️ 副作用一：字面量含 `%s` 会被 `I18n.get` 当格式串（古文无 `%`，安全；若将来有，写 `%%`）。
  - ⚠️ 副作用二：正文走 Markdown 渲染 —— 古文标点（，。：；「」）安全，但**方括号 `[]` 会被当链接**、`*`/`_` 会被当强调，照录时留意。
- **长文分段**：按意群拆成多段原文页，**与译文页一一配对**（跨页左原文右译文）。

### 3.2 白话译文页（lang 三语）
- 现有各条目 3 页白话正文**即译文段**，文案不重写；改版 = 重排页面串 + 按需拆页对齐原文段。
- **逐段对照排版**（配合双页模式）：较长的节排成 `原文段1｜译文段1 → 原文段2｜译文段2 …`，每翻一跨页都是左原文右译文，仿注疏对读；短文则一段原文一段译文即可。
  - **页码纪律**：原文页与译文页必须**相邻成对且原文在前**（原文段A 落在偶数位、译文1 落在奇数位），才配成"左原文右译文"。译文若多于原文段，把原文段再拆细以对齐（水利节即原文 3 段 ↔ 译文 3 页）。
- 文中 mod 元素名词挂内链（见 §4 链接规范）——**直接写进 lang 值**，格式 `[筒车](entry://naili_juan/naili_shuili@tong_che)`。

### 3.3 本节涉及 · 档案段（spotlight / text）
- 页型：物品/方块用 `modonomicon:spotlight`（title=名字 / text=档案文字 / item=该物）。
- 档案文字要点：这是什么、从哪来（哪个条目解锁/何种玩法产出）、书里怎么用。走 lang 三语键。
- 机制类（如水培、缺水枯秆、收穗留秆）没有单物品可指：用 text 页，或指向代表性方块（秆/穗）做 spotlight 再补一段机制文字。
- **内链目标**：译文里点元素名词 → 跳到本条目（或他条目）对应档案页；此页即"介绍的那一页"。

### 3.4 核心加工链页（crafting 等）
- 只放 ≤1–2 张/节，选"本条教的就是这个"的链。例：稻 → 脱粒 1 稻谷=1 米；后续舂米方块落地后，稻节换/补舂米加工页。
- 杂项合成（玩家能靠 JEI 搜到的）一律不收录。

### 3.5 插图（远期增强，2026-09-08 用户规划）
- 待古籍扫描图/游戏截图+滤镜仿版画素材就绪后，用 `modonomicon:image` 页穿插（如原书版画、卷首图）。
- 素材制作独立排期，不进本轮模板落地。

## 4. 内链规范（2026-09-20 反编译实测确认 ✅）

正文一律走 **Markdown**。链接语法取自 `BookLink` 的协议常量（`PROTOCOL_BOOK/CATEGORY/ENTRY`）与 `ItemLinkRenderer`（`item://`）：

| 目标 | 语法 | 说明 |
|---|---|---|
| 本条目某页 | `[文字](entry://<分类id>/<条目id>@<锚点>)` | 锚点 = 目标页的 `anchor` 字段；省略 `@…` 则跳该条目首页 |
| 同书其他条目 | `[文字](entry://<分类id>/<条目id>)` | 分类/条目就是 entry 串的两段（如 `naili_juan/naili_shuili`） |
| 跨书条目 | `[文字](entry://<bookId>/<分类id>/<条目id>)` | 串里含 `:` 时，首段（`<ns>:<book>`）作 bookId |
| 整个分类 | `[文字](category://<分类id>)` | |
| 整本书 | `[文字](book://<bookId>)` | |
| 物品 | `[文字](item://<ns>:<item_id>)` | 点击显示实例物品（`ItemLinkRenderer`） |
| 外部网页 | `[文字](https://…)` | 标准 Markdown，官方 demo 即此法 |

- **锚点 = 档案页入口**：档案段每页给 `anchor`（如 `tong_che`），译文里的装置名就链到它；`craft_<id>` 用于指向合成页。
- **落地示例（水利条目已用）**：`河湍处立[筒车](entry://naili_juan/naili_shuili@tong_che)：轮上缚竹筒…`
- **跨卷链接先别写**：目标条目不存在时链接会失效——但 `book.json` 已开 `allow_open_book_with_invalid_links: true`，**不会崩、只是点了没反应**。故粹精卷等未做的卷，暂不写跨卷内链。
- **兜底仍在**：档案页 spotlight 图标保留"点击开 JEI"（`showRecipe/showUses`），杂项合成靠它。

## 6. 双页配对与对齐策略

- 双页模式按跨页配对（页0|页1、页2|页3…，实际配对以游戏实测为准）。
- 译文/档案需要严格"左X右Y"时，用 **BookEmptyPage** 或调整段落页数把目标页顶到偶数/奇数位。
- **该节装置数为奇数时，末尾补一张 empty 页**，使后面的合成页从新跨页起——否则会出现"装置+配方"混搭在一跨页上。

**样板页面串（水利条目，2026-09-20 落地，共 20 页）**

| 页 | 内容 | 配对效果 |
|---|---|---|
| 0 / 1 | 原文段A ／ 译文 page1 | 左原文右译文 |
| 2 / 3 | 原文段B ／ 译文 page2 | 左原文右译文 |
| 4 / 5 | 原文段C ／ 译文 page3 | 左原文右译文 |
| 6–14 | 9 个装置 spotlight（锚点 tong_che…feng_fan_che） | 每跨页并排两个装置 |
| 15 | empty（补位） | |
| 16 / 17 / 18 | crafting 筒车 ／ 传动轴 ／ 梘 | 配方成对 |
| 19 | empty | |

- 落地首个样板 = **水利条目**（装置最全、书里 8 组知识点都已实现），跑通后批量套其余条目。
