# 教程书页面排版模板设计

> 定位：天工开物 mod 教程书（Modonomicon，当前《乃粒》卷）的**通用页面模板规范**——每一条目（=原书一节）按固定页面串排版，让书同时具备"古籍原典""白话知识""实物图鉴/索引"三种功能。
> 状态：**设计定稿（2026-09-08 用户拍板）**；落地执行排在乃粒玩法实物（#33/#34/#35 与核心加工链）之后，避免链接目标不存在造成返工。
> 相关：docs/乃粒篇大纲.md（内容蓝图）、docs/乃粒稻作玩法设计.md（玩法机制）。

---

## 1. 核心理念

1. **原文是玩法本体**：文言原文 = 内容数据，任何语言玩家读到同一份（与翰墨台题库 wenyan 同口径），不随语言翻译。
2. **白话是译注**：正文白话 = 原文章节的意译讲解，走 lang 三语。
3. **知识可点可查**：译文/档案中提到的 mod 元素（物品/方块/机制），能点击跳到**书内介绍它的那一页**；核心加工链在书内直接可见，杂项合成靠 JEI 点击兜底。

---

## 2. 页面串总览（每条目 = 原书一节）

```
┌ 文言原文页（1~N，内容数据）─────────────────┐
│  题记式排版：条目名在上，居中文言原文，        │
│  页脚注出处《天工开物·乃粒》                   │
└──────────────────────────────────────────────┘
┌ 白话译文页（1~M，lang 三语）─────────────────┐
│  原文的意译讲解；文中出现的 mod 元素名词       │
│  挂【内链】→ 跳到对应档案介绍页                │
│  （现有 3 页白话正文 = 译文段，直接沿用）       │
└──────────────────────────────────────────────┘
┌ 本节涉及 · 档案段（每元素 1 页）──────────────┐
│  spotlight 页：物品/方块大图标 + 名字          │
│  + 档案介绍文字（这是什么、书里怎么用）        │
│  （机制类无实体物 → text 页写清对应玩法）      │
└──────────────────────────────────────────────┘
┌ 核心加工链合成页（≤1~2 页/节）────────────────┐
│  crafting（或 smelting/processing）页，        │
│  只放"本条教的就是这个"的链（例：脱粒          │
│  稻谷→米；未来舂米）。杂项合成一律不收录，      │
│  靠 JEI 点击兜底。                             │
└──────────────────────────────────────────────┘
```

**页数不定长**：视该节内容多少增减档案段数量；纯知识节（无新实物）可以没有档案段。

## 3. 逐条规范

### 3.1 文言原文页（内容数据）
- **来源**：直接复用翰墨台题库 `hanmotai/puzzles/` 中该条目的 wenyan 字符串，不新写文案。
- **语言口径**：三语显示**同一份原文**（不入 lang 翻译体系；同题库"wenyan 是源文本永远单一"铁律）。
- **实现注意**：Modonomicon text 页当前走 lang 键。文言若要"三语同一串"，落地方式二选一（改书时先用最小样张验证哪个稳）：
  a) 条目 JSON 页 text 直接写字面量（若引擎支持原样渲染）；b) 三语 lang 各存一份相同文言串。
- **长文分段**：原文较长时按意群拆成多段原文页。

### 3.2 白话译文页（lang 三语）
- 现有各条目 3 页白话正文**即译文段**，文案不重写；改版 = 重排页面串 + 按需拆页对齐原文段。
- **逐段对照排版**（配合双页模式）：较长的节排成 `原文段1｜译文段1 → 原文段2｜译文段2 …`，每翻一跨页都是左原文右译文，仿注疏对读；短文则一段原文一段译文即可。
- 文中 mod 元素名词挂内链（见 §4 链接规范）。

### 3.3 本节涉及 · 档案段（spotlight / text）
- 页型：物品/方块用 `modonomicon:spotlight`（title=名字 / text=档案文字 / item=该物）。
- 档案文字要点：这是什么、从哪来（哪个条目解锁/何种玩法产出）、书里怎么用。走 lang 三语键。
- 机制类（如水培、缺水枯秆、收穗留秆）没有单物品可指：用 text 页，或指向代表性方块（秆/穗）做 spotlight 再补一段机制文字。
- **内链目标**：译文里点元素名词 → 跳到本条目（或他条目）对应档案页；此页即"介绍的那一页"。

### 3.4 核心加工链页（crafting 等）
- 只放 ≤1–2 张/节，选"本条教的就是这个"的链。例：稻 → 脱粒 1 稻谷=1 米；后续舂米方块落地后，稻节换/补舂米加工页。
- 杂项合成（玩家能靠 JEI 搜到的）一律不收录。

### 3.5 插图（远期增强，2026-09-08 用户规划）
- 待古籍扫描图/游戏截图+滤镜仿版画素材就绪后，用 `modonomicon:image` 页穿插（如原书版画、卷首图）。
- 素材制作独立排期，不进本轮模板落地。

## 4. 内链规范（待实测的技术点，标记 ⚠️）

- **目标**：译文正文中"稻谷""米""水田"等名词可点击，直接跳到**介绍它的档案页**（本条目或其他条目），而非外部链接/JEI。
- **技术底牌（已核实存在）**：
  - 条目屏有 `linkhandler` 包（LinkHandler 机制）+ 文本点击事件（`getClickedComponentStyleAtForPage`）。
  - book.json 有 `allow_open_book_with_invalid_links` 键 → 说明书内链接在加载期会被校验有效性，存在"合法/非法链接"概念。
- **未知**：Modonomicon 正文（Markdown）声明"跳某条目某页"链接的**确切语法与支持范围**。
- **动作**：改书前先做 1 页最小样张（A→B 条目互跳 / 同条目内跳页）实测；语法走通则逐词内链，走不通则回退：
  - **回退方案 A**：译文提到元素处不改词，改为段落右上/页脚放小号图标按钮跳档案页。
  - **回退方案 B**：译文末行固定"→ 本节涉及：〔稻谷〕〔米〕〔水田〕"图标行，点图标跳档案页。
- 档案页 spotlight 图标保留"点击开 JEI"能力（JEI 集成 showRecipe/showUses 已核实），作杂项合成兜底。

## 5. 技术要点记录（反编译核实，2026-09-08）

| 能力 | 结论 |
|---|---|
| 双页展开 | book.json `page_display_mode: "double_page"`（枚举 DOUBLE_PAGE/SINGLE_PAGE；另有 `single_page_texture`/`book_content_texture` 底纹）——"左原文右译文"的开关 |
| 物品展示 | `BookSpotlightPage`（title/text/item）✅ |
| 合成/加工 | `BookCraftingRecipePage` + Smelting/Processing/Smithing/Stonecutting/Blasting/Campfire/Smoking ✅ |
| 点物品开 JEI | `ModonomiconJeiIntegrationImpl.showRecipe/showUses` ✅（仅 JEI/REI/EMI 环境存在时） |
| 正文排版 | Markdown 渲染（prerenderMarkdown/BookTextRenderer），可做题记式居中留白 |
| 空页占位 | `BookEmptyPage`（修跨页奇偶对齐用）✅ |
| 链接通道 | LinkHandler + `allow_open_book_with_invalid_links` 存在，语法待样张实测 ⚠️ |

## 6. 双页配对与对齐策略

- 双页模式按跨页配对（页0|页1、页2|页3…，实际配对以游戏实测为准）。
- 译文/档案需要严格"左X右Y"时，用 **BookEmptyPage** 或调整段落页数把目标页顶到偶数/奇数位。
- 落地首个样板 = 稻条目（玩法和页面最全），跑通后批量套麦/谷豆/总论。
