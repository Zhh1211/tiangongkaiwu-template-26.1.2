# 结构方块使用手册（多方块模板导出）

> 目的：你在游戏里把机器的骨架**摆出来**，用结构方块存成 `.nbt` 交给 AI，
> AI 解析后自动生成多方块模板 JSON——模板永远和你摆的完全一致，不用手写坐标。

---

## 第〇步：约定（给 AI 的"角色"信息）

编译时 AI 要知道结构里每个特殊位置的角色。你摆的时候这样配合：

| 位置 | 怎么标 |
|---|---|
| **核心** | 碓这类自带特殊方块的机器：核心就是那个机器方块本身。通用情况：放一块**金块**当核心标记（编译时剔除） |
| **木料位** | 随便什么原木/木板，种类不限（编译后转成"任意木料"tag；补料时优先匹配你摆的种类） |
| **料口** | **直接放一个漏斗**（2026-10-04 拍板：漏斗=料口本体，成型必需，视觉自说明；黄色混凝土标记仍兼容） |
| **杵位/运动件位** | 留空即可（每台机器的运动件位置由 AI 编译时按设计标注） |
| **轴位** | 放一根传动杆占位（编译时转成包壳轴接口） |

> 标记方块（金块/黄色混凝土）只是**存进 nbt 的语言**，编译成模板后全部剔除，游戏里不会出现。

- **不用管朝向**——编译器做四向旋转匹配，摆一次就够
- 摆完拿个便签记下：料口/轴位/杵位大概在哪（"料口在梁上中间"这种描述就够）

## 第一步：拿方块

进测试世界（`runClient` 起的存档，创造模式）：

```
/give @s minecraft:structure_block
```

## 第二步：框选（两种方法选一）

**方法 A：两方块法（推荐，省心）**

1. 在结构**一角**放结构方块 → 右键打开 → 左上角模式切到 **角落（Corner）** → 名字填 `tiangongkaiwu:dui_frame`
2. 在**对角**放第二个结构方块 → 模式切到 **保存（Save）** → 名字填**同样的** `tiangongkaiwu:dui_frame` → 点 **探测（DETECT）** 按钮 → 白色线框自动包住两个角落之间
3. 微调：白框应把整个结构**连同一圈空气**都框进去（改 相对位置/大小 数字即可）

**方法 B：单方块手调**

放一个结构方块 → Save 模式 → 手填 相对位置（offset，可负）和 大小（size）→ 白框预览对准结构。我们的结构都很小（3×5×4 级别），手调也不难。

## 第三步：保存

Save 模式下点 **SAVE** 按钮。文件立刻生成在：

```
G:\workspace\tiangongkaiwu-template-26.1.2\run\saves\<你的世界名>\generated\tiangongkaiwu\dui_frame\structure.nbt
```

⚠️ 名字**必须带 `命名空间:` 前缀**（`tiangongkaiwu:xxx`）才会存进 `generated\` 子目录；
不带前缀会存到世界目录的 `structures\` 下，也能用，但路径不同。

## 第四步：交给 AI

告诉 AI 三样东西：

1. nbt 的路径（或直接说"在 run\saves\<世界>\generated\ 里，名字 xxx"）
2. 结构名对应哪台机器（比如"这是碓的"）
3. 有没有朝向要求（一般没有）

（角色已由标记方块自说明，不用再口头描述；只有杵位这类机器专属语义由 AI 编译时标注。）

## 注意事项

- **实体**（动物、掉落物）默认不保存，不用清理场地
- **空气也会被记录**——料口留空是正常数据，不是丢失
- 尺寸上限 48³，我们的结构绰绰有余
- 改动结构后**同名重新 SAVE** 即可覆盖，AI 重新编译一遍
- 想要"加载回来看效果"：另拿一个结构方块切 **加载（Load）** 模式，同名即可把结构原样放出来（验收用，非必需）
