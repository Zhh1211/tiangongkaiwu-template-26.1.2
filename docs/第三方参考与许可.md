## 二、借鉴的三档（规则）

1. **玩过、看行为**——零风险，什么 mod 都行。
2. **读源码学架构**——开源 mod 都可以（人家开源就是给人看的，这不是反编译）；学算法、学结算频率、学数据结构，自己写。
3. **复制代码进我们 mod**——只对 MIT 家（Create/Flywheel/Mekanism/GeckoLib）成立：**文件头保留其 MIT 版权声明**（`Copyright (c) The Create Team` 等），其余随意；IE 这类自定义许可的一律不搬。
4. **资产红线**：所有 mod 的贴图/模型/音效默认别碰（Create 明确 All Rights Reserved）；我们本来就全自产，无冲突。

## 三、实操：把参考源码放到本地（供 AI 阅读）

沙箱连不上 github.com，但 G 盘即物理机——**用户跑一条命令把参考仓库 clone 到本地**，AI 即可直接读第一手实现（比看博客/凭记忆准得多）：

```
git clone --depth 1 -b mc1.21.1/dev https://github.com/Creators-of-Create/Create.git G:/workspace/_refs/Create
```

- 分支 `mc1.21.1/dev` 已核实存在（与我们 MC 版本一致）。
- 建议顺手再 clone（可选）：Mekanism（流体管道网络）、Flywheel（GPU 渲染，远期）。
- 参考仓库放 `G:/workspace/_refs/`，不进本项目 git。
