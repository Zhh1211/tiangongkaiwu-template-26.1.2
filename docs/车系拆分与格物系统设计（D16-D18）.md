## D16 · 车系拆分：筒是筒、车是车

### 定位
- **车 = 劲的生产者**（家族）：水车（原 `tong_che` 方块**原位改名**，12 劲，flowScore 门槛与 BER 大轮全保留）/ 牛车 10 / 踏车 5 / 拔车 2 / 风帆车（批 4，**纯产劲**）
- **筒 = 劲的消费者·流体机器**（新方块 `tong`）：定额 3（一台筒一份劲，不叠加计费），档位**不及则慢**：3 劲=每周期干活 / 2=两周期一次 / 1=三周期一次 / 0=停。对偶碓的「不及则粗」——劲只决定转不转+干活频率，永远不决定速度（D13 不破）

### 流体单位改革（D9 修订）
- **1 源方块 = 1B = 1000mB**，计量只有 mB/桶，**「级」段级抽象整体退役**（梘段不再有 LEVEL 0-15 状态）
- 梘**不存流体**：与机动/砧艺对齐，管道不存水——水存于**梘网库存**（单 FluidStack，总容量 = 段数 × 1000mB），段只是显示窗口（渲染按库存分摊的填充率画液面，低处组先满溢高处组）
- capability 对网库存；灌田按 mB 扣网（1 格田水 = 1000mB）
- 社区共识单位，capability 对外数值不再有换算
- 旧档迁移：各段旧级数 ×100mB 求和 = 网络初始库存 mB

### 梘网 = 连通器（D7 梯度规则修订）
- **删除「每两格降一级」衰减**——它是抽象损耗模型，与真实流体量互斥（衰减=毁水）
- 新规则：水往低处流、全网趋向平水位，**总量严格守恒**；远距离输水的挑战从「衰减接力」变为「总水量要够」
- **梘=渠不是容器**：网库存（单 FluidStack）+ 段=显示窗口（等效高度分组定显示水位）；capability 对网库存
- 旧档自愈：各段旧级数 ×100mB 求和 = 网库存

### 筒 · 两形态（形态即安装位）

**泵形态**（筒物品**右键梘段**安装，附着于段；潜行右键拆下退还）
- 提水泵：水不能上山（D7「向上永不流」），泵段吃劲把水**从低段搬到高段**（网内守恒：低 −1、高 +1）——山地灌溉 = 泵链；平地网里的筒闲置（Jade「无需提水」）
- 流向由**劲传入的方向**决定（轴在哪侧），无需玩家选向；「当格内轴反转」的主意待用户细说
- 「中继器」概念退役：守恒模型没有衰减可补；砧艺（AnvilCraft）式「泵势场/等效高度」为实现参考（`_refs/AnvilCraft`，FluidPipeNetwork：高→低分配、低组先满才溢高组、流速随高差线性）——实现取局部近似，全局收敛为目标

**滑轮形态**（筒独立放置，空手右键循环四模式）

| 模式 | 行为 | 水账 |
|---|---|---|
| 汲·单格 | 邻侧世界源方块（任意流体）→ 移除 → 网库存 **+1000mB** | 守恒（1格=1B） |
| 泻·单格 | 网库存 **−1000mB** → 世界造源方块（下方>水平>上方） | 守恒 |
| 汲·无限 | 邻侧连通体批量抽取：**<200 整抽消散一次到底；200~10000 逐步可抽干；≥10000 判「无限供应」抽取不消耗**（Create 同款三层判定，防熊自带） | **销毁**（明示） |
| 泻·无限 | 网库存灌满连通空气区（≤200 格）：逐格扣 1000mB 造 1 源 | 守恒（库存出） |

- 不限雨天（劲已是门槛，D14「雨天运转」随风帆车排涝职责一并退役）
- 支持任意流体（D12 精神；灌田逻辑只认水，熔岩自然不灌）

### 配套
- 车系直喂删除：JianBlock ②「下方有运转车系直接喂水」移除；**桔槔/辘轳保留直喂**（井具本职提水，不吃劲不经筒）
- 配方：筒 = 竹 ×2 + 木板 ×3；水车沿用原配方
- Jade：筒显示形态/模式/劲档位/连网状态；水车照旧
- 书页：水车条目微调；「筒车」= 水车+筒的组合概念，讲链不讲单方块（3.5d）
- 旧档自愈：`tong_che` id 不动零成本；旧「车下喂梘」场景给提示

### 红线
**18 卷内：不电、不化、不热机**（蒸汽也算热机，保「劲」体系纯粹）；材料可上铁（锤锻卷有铁器）。

## D17 · 格物系统（可选 QoL 支线，札记先行）

### 定位（与翰墨台双轨）
- **翰墨台 = 必选主树**：残页→译书→解锁各卷核心玩法
- **格物 = 可选 QoL 支线**：现代人的纯机械巧思，**省操作不改规则**（解锁前笨办法永远可用，平衡零成本）
- 红线同 D16；「工业革命」见 D18

### 格物札记（MVP，随车系批落地）
- 获得：翰墨台译出「巧法」条目时附带；纸+墨也可合成
- tooltip 三件套：**文言谜面**（原理）+ **白话目标**（效果）+ **材料清单**
- 判定两型（研究 JSON `type` 字段，与 structures 同款数据管线，新研究零代码）：
  - `structure`：照谜面在世界里摆结构 → 手持札记右键锚点 → matchAt 判定（复用墨斗成型逻辑）
  - `items`：贡物料——提交材料清单即致知（没有空间结构的巧法不硬凹摆法）
- **台评梯度反馈**：摆错/未齐时消息提示部件计数与模糊方位（「四轮已具其三，然方位未合」），永不给答案
- 致知 = 配方解锁（advancement 原生 rewards）+ toast + 书条目点亮；只锁配方不锁使用
- 结构不消耗（实验台原样供着当装饰）

### 格物池（12+，三类）
- 传动（摆结构）：十字齿轮箱（劲换向/分流）、止逆轮（防倒转）、离合器（劲网断接器，检修不用拆杆）、链传动（柔性转向）
- 流体（摆结构）：水塔（高位储水）、虹吸管（跨壑输水）、双动风箱（远期冶炼）
- 工具（贡物料）：量水尺（梘网水位仪表）、曲轴试件（旋转劲→自动踩踏）、曲辕犁（耕地范围）
- 首个研究：**合轮**（十字齿轮箱）——泵流向反转不再拆轴重接

### 格物台实体（远期，札记攒到 5+ 再建）
