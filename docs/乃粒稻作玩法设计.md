## 0. 设计总纲

> **书 = 玩法说明书，玩法 = 书的实验。** 解锁哪篇知识 → 能玩到哪套玩法；
> 书页讲的每一件事，游戏里都能亲手做、做了有回报。
> 现水稻（旱地版小麦形态）与书全面脱节 → **重做为两格水培稻**。

## 1. 稻作玩法闭环（玩家视角）

```
[首获 4 谷·解锁奖励] → [挖沟灌水造田] → [水面播种] → [秆长成] → [抽穗成熟]
    ↑                                                                  ↓
[解锁稻事各篇] ← 翰墨台翻译 ← 拿残页 ← [收获稻谷] ← 打上部稻穗
                          ↘ 秆留着，再长新穗（再生）
```

- **造田**（稻工·水利）：离水源挖 1 格沟 → 灌静止水 → 水面插稻 → 底部须为可作田的土（泥土系/泥/沙/砂砾/粗泥/黏土，**底材决定保水天数**），一格浅水
- **养田**（稻宜）：✅ **v1 已落地（2026-09-19）**——粪肥通用、骨灰/石灰只宜冷浆土、烧土只宜坚紧土，用错即「不宜也」；骨粉已弱化；细糠喂猪（犬豕）得粪肥。详见 §3.8
- **管水**（稻灾 · 水利）：田水按底材蒸发，雨天/沟渠回充；见底水面退去、枯秆约旬日方死 → 倒水或等雨救活；空桶可主动取水
- **扩田**（水利 B/C 批 ✅）：**筒车**（3×3 大轮，流水自转）+ **梘**（引水槽）把水引到远田；配套**传动轴**构成动力网。动力源已四种：筒车 12（水力）／牛车 10（拴牛）／踏车 5（人踩）／拔车 2（人摇），为舂米等加工供能。井具（桔槔／辘轳）与风帆车（排水）见 §3.9 —— 水利至此收尾

## 2. 书条目 ↔ 玩法机制 映射

| 书条目 | 书页知识 | 机制落法 | 玩家验证动作 |
|---|---|---|---|
| 稻 | 稻在水中长、刈获 | **两格水培**：下部浸水稻秆 + 上部稻穗（成熟才有） | 造田、水面插稻、看它秆穗两段长出来 |
| **稻宜** | 粪田养地 | ✅ **v1 已落地**：**粪肥**通用催熟；**骨灰/石灰**只宜冷浆土（黏土田）；**烧土**（潜行+柴）只宜坚紧土（砂砾/粗泥田）；骨粉弱化 | 骨粉→没什么用；粪肥→立见成效；把骨灰撒在沙田→被驳回「向陽暖土不宜也」 |
| **稻工** | 灌溉造田、农时 | 造田=挖沟引水；**收穗留秆再生**=一种多收 | 打穗不毁秆，田越种越熟 |
| **稻灾** | 旬日失水则死 | **缺水即枯**（水利 A 已落地）：田水按底材蒸发 → 见底 → 枯秆；枯秆约旬日方死 | 铺沙田看它三天就干；不浇水就枯黄；倒水或等雨救活 |
| **水利** | 稻独甚借水；筒车/踏车引水 | **A ✅**：底材定保水天数 + 雨/沟渠回充；**B ✅**：筒车（流水自转、栓木停机、动力 12）+ 梘（引水槽）+ 传动轴（动力网）；**C ✅**：牛车 10／踏车 5／拔车 2（龙骨车三驱动）；**D ✅**：桔槔／辘轳（井上小汲，最慢档）、风帆车（雨天排水） | A：沙田 vs 黏土田比干涸；B：垒堰 → 造筒车 → 梘引水到远田；C：牵牛／踩车／手摇，三档动力当场比得出 |

## 3. 机制细化（v1 拍板定稿）

### 3.1 水培稻方块（核心，参考农夫乐事 RiceBlock 结构）

**两段结构**：
- **下部：`rice_stalk`（秆）**——waterlogged，AGE 0–7（沿用 `BlockStateProperties.AGE_7`）。
  - 种植：手持 `rice_grain` 对静止水源右键 → 水源格被替换为 `rice_stalk`（waterlogged=true、田水 moisture=7；底部须为可作田的土：泥土系/泥/沙/砂砾/粗泥/黏土）；上方必须空气。
  - 生长：随机 tick 仅在 `waterlogged=true` 时递增 AGE（约每 8 tick 一档）。AGE 满 7 时，若上方是空气 → 在其上方放置 `rice_panicle`（两格高完整态）。秆生长与抽穗概率可在实现时调。
  - 收获再生：打上部 `rice_panicle` → 秆（AGE 7）`setValue(AGE, 3)` → 秆可视地"缩回半截"再长回来；下次抽穗。
  - 打秆（打 `rice_stalk`）：**age==7 掉 1 粒保本**；未成熟（age<7）无掉落。秆毁时上方 `rice_panicle` 自动断裂正常掉粒（由 panicle 的 `neighborChanged` 触发）。
  - 通行：`noCollission()`，玩家/水流可穿过。
  - 骨粉：v1 暂接受骨粉催熟（performBonemeal +1..2 stage），#32 后续批再弱化/无效化。
- **上部：`rice_panicle`（穗）**——非水方块，仅作为成熟态视觉/收获入口。
  - 自毁条件：下方不是 `rice_stalk`（包括被掘、被舀空水后枯变等）→ 自毁带掉落。
  - 打穗：玩家破坏 → `playerWillDestroy` 把下方秆 AGE 重置为 3 → 秆复位后再生。稻谷由 `playerDestroy` **代码直弹**（2–3 粒 + 时运每级 +0~1），不走 loot table——破坏路径确定、与数据包加载解耦。秆毁穗断（neighborChanged）同样代码直弹。

**田水与枯死（水利 A · 2026-09-19 落地）**：
- **田水 = `rice_stalk` 新增 `moisture` 0–7**（满 = 刚灌过），随机 tick 结算：
  ① **下雨** → 不蒸发、缓缓回满（书：天澤不降，則人力挽水以濟 —— 反过来说降了雨就不必挑水）；
  ② **邻格有水**或邻格是带水的同类稻田（沟渠／连片水田）→ 缓缓回满；
  ③ 否则按**底材**概率蒸发：**沙≈3 天、砂砾/粗泥（磽）≈4 天、泥土/泥（泥）≈6–7 天、黏土（膩）≈半月**（书：厥土沙、泥、磽、膩，隨方不一，有三日即乾者，有半月後乾者）。
  数值集中在 `RiceStalkBlock` 顶部常量，随时可调。
- **田面见底**：moisture < 3 → 自动 `waterlogged=false`，水面可视地退去并**停止生长**（"该挑水了"的提示）。
- **干涸**：moisture 归零 → 转 `rice_stalk_dry`（**保 AGE**）；上方 `rice_panicle` 经 neighborChanged 自毁掉谷（已结的谷仍能收）。
- **干秆 `rice_stalk_dry`**：不生长、不抽穗；随机 tick 以 ≈1/176 概率枯死（约合书里"旬日失水则死"，留出抢救窗口），死时无掉落。
- **救活**：① 手持**水桶**右键干秆 → 复活为同 AGE 稻秆并灌满田水，同时返还空桶；② **下雨**时随机 tick 自动复活（同 AGE、田水满）。
- **主动取水**：手持**空桶**右键浸水稻秆 → 一次取走 3 格田水（取到见底则转枯秆），并给玩家水桶（创造模式只改状态不发桶）。
- **可作稻田的底土**（`canSurvive`）：泥土系 / 泥巴，外加书里点名的 **沙 / 砂砾 / 粗泥（磽）/ 黏土（膩）** —— 所以"沙田三天干、黏土半月干"玩家能自己铺出来验证。
- **Sponge 自然吸水路径**：与本批机制无关，留作海绵边界（玩家在创造里玩）。

### 3.5 水利装置（B/C 批 · 2026-09-19 落地）

**动力系统（模块化 · 机械动力的简化版）**：动力源 → 传动轴 → 加工机器（后续批）。

| 方块 | id | 作用 |
|---|---|---|
| 筒车 | `tiangongkaiwu:tong_che` | 3×3 大轮，**放一格自动展开、挖任意一格整台收回只掉一个**；车下须有**流水**方转（书：堰陂障流，激轮使转；静水不转）；空手右键**栓木**停机；输出**动力 12**，并给邻接的梘／稻田送水 |
| 牛车 | `tiangongkaiwu:niu_che` | 龙骨车·长车（3 格，放一格自动展开）；**近旁有被拴绳系住的牛**则转（书：以牛力转盘）；动力 **10**（牛则倍之） |
| 踏车 | `tiangongkaiwu:ta_che` | 龙骨车·长车（3 格）；**有人站在车上**踏转则转（书：聚数人踏转）；动力 **5**（一人竟日五亩） |
| 拔车 | `tiangongkaiwu:ba_che` | 龙骨车·短车（1 格）；**有人立在车旁**摇转则转（书：一人两手疾转）；动力 **2**（短车二亩而已） |
| 梘 | `tiangongkaiwu:jian` | 定向输水：每格看**上游一格**（带水的梘／在转的车或轮／一格水）→ 槽内积水，并约每 2 秒给挨着的稻田 +1 田水（枯秆也救活）。能把水**引过地形**、送到远处——挖沟做不到 |
| 传动轴 | `tiangongkaiwu:shaft` | 动力网：本格动力 = 邻格最大动力 **−1**（每格衰减 1，故有射程）；有动力时换铜箍贴图 |

- 动力数值**直接取自书里效率刻度**：筒车 **12**（昼夜不息，百畝無憂）／牛车 **10**（牛则倍之）／踏车 **5**（一人竟日五畝）／拔车 **2**（短车二畝而巳）——四种动力源现已全部落地（C 批 2026-09-19）。
- 实现：`scheduleTick` 自调度 + 纯局部规则传播，**不需要方块实体**——这是本项目自动化的地基。
- 配方（**有序**）：传动轴 = 木棍／木板／木棍（得 4）；梘 = 竹＋木板（2×2，得 2）；筒车 = 木板×6 ＋ 绳×2 ＋ 竹×1（9 格，得 1）。
- 龙骨车三驱动（**有序**）：牛车 = 木板／木棍×2／绳 ＋ 框（车架最费料）；踏车 = 木板 ＋ 竹踏板 ＋ 绳；拔车 = 木板×6 ＋ 木棍×2 ＋ 绳（最省）。三者都**须临水**（湖池静水即可，不必像筒车要激流）。
- 转动视觉：轮盘做成 4 帧**动画贴图**（16×64 竖条 + `.mcmeta`，游戏自动播放，零 tick 开销）；栓木后切静态贴图，肉眼可见地停住。
- 龙骨车（牛车/踏车/拔车）：槽身 + 龙骨板（运转时是流水 + 板条平移的 4 帧动画，停机时干涸木槽），中段带驱动轮；牛车多一道牛轭横梁、踏车多一块竹踏板、拔车是小摇轮。长车 3 格横铺（垂直于玩家朝向），挖任意一格整台收回只掉一个。

### 3.6 舂米（碓 · 2026-09-19 落地）

依据《天工開物·粹精·攻稻》（原文存档 `docs/天工开物·粹精原文.md`）：
「凡稻去殼用礱，去膜用舂……**水碓主舂，則兼併礱功**」「**不及則粗，太過則粉**」
「既舂以後，皮膜成粉，名曰**細糠**，以供犬豕之豢」「凡水碓……**引水成功，即筒車灌田同一制度也**」

| 方块／物品 | id | 说明 |
|---|---|---|
| 碓 | `tiangongkaiwu:dui` | 动力网的**第一个消费端**：相邻（六向）有传动轴或动力源即自转；**料从上方容器取、产物入下方容器，下方没容器就弹出**；一臼一格，摆几个就几臼（书：並列十臼無憂） |
| 糙米 | `tiangongkaiwu:brown_rice` | 动力不足（轴上 power < `min_power`）时的产物——书「不及則粗」；送回碓（再放进上方容器）即得白米 |
| 细糠 | `tiangongkaiwu:rice_bran` | 副产物，「皮膜成粉」（书：以供犬豕之豢） |

- **加工配方数据驱动**：自定义配方类型 `tiangongkaiwu:pounding`，JSON 放 `data/tiangongkaiwu/recipe/*.json`
  （与 vanilla 同目录、靠 `"type"` 区分——已实测确认 1.21.1 全部配方类型共用一个 `recipe/` 目录）。
  字段：`input` / `min_power` / `result`+`byproduct` / `coarse`。以后加麦（磨面）、黍稷粟只需加 JSON。
- 现有两条：`pounding_rice`（谷 → 米＋细糠，动力≥3，不足出糙米）、`pounding_brown_rice`（糙米 → 米＋细糠；**无 coarse**，动力不足就干等，不糟蹋料）。
- **"全自动"链路**：动力源 → 传动轴 → 碓上方漏斗喂谷 → 米自动进下方箱子。**碓自身无方块实体**（沿用 B/C 批 scheduleTick 局部规则），不需要 GUI。
- **动力刻度对照**：拔车链（轴上 1）→ 只出糙米；踏车链（4）→ 出白米；牛车／筒车链更强，同样达标。
  书里「一人五畝 : 牛倍之」的效率差，在碓上体现为"够不够舂透"，正是「不及則粗」。
- 碓本体配方（有序）：`PLP / SSS / SIS`（木板×2、原木×1、石×4、铁锭×1）。

### 3.7 JEI 兼容（2026-09-19）

- **合成配方**（筒车／梘／轴／牛车／踏车／拔车／碓）：都是原版 `crafting_shaped`，JEI 装上即自动显示，不需要插件。
- **加工配方**（碓：谷→米＋糠）：自定义 JEI 分类 `jei.tiangongkaiwu.category.pounding`，
  显示输入／白米／细糠／糙米四个格位与「需动力 ≥ N」说明；碓本体作为该分类的**催化剂**（JEI 里点碓即可查到能干什么）。
- 依赖接入方式：`compileOnly` 两个 API + `localRuntime` 完整 JEI（**可选集成**，mod 本身不硬依赖 JEI；开发客户端内存吃紧可注释掉 localRuntime）。

### 3.8 稻宜 · 粪田（对症肥料 · 2026-09-19 落地，v1）

依据《天工開物·乃粒·稻宜》（见 `docs/乃粒·稻宜粪田设计.md`）。书里的结构很硬——**土性不同，改土法不同，用错"不宜也"**：

| 书里的话 | 游戏里 |
|---|---|
| 人畜穢遺……普天之所同也 | **粪肥** `fen_fei`：通用催熟（+2~3 档，必成） |
| 土性帶冷漿者，宜**骨灰**蘸秧根（凡禽獸骨） | **骨灰** `gu_hui`：只对**冷浆土（黏土田）**有效 |
| 宜**石灰**淹苗足，**向陽暖土不宜也** | **石灰** `shi_hui`：同上；撒在沙/泥土田上会被驳回 |
| 土脈堅緊者，宜耕壟，**疊塊壓薪而燒之**，**填墳鬆土不宜也** | **烧土**：潜行 + 手持柴右键稻田；只对**坚紧土（砂砾/粗泥田）**有效 |

- **土性判定复用 A 批那张底材表**：黏土 = 冷浆土；砂砾/粗泥 = 坚紧土；泥土/泥/沙 = 普通瘦田（认粪肥）。
- **用错不消耗**，只弹一句书里的原话（"向陽暖土不宜也" / "填墳鬆土不宜也"）——把书里那句警告做成手感。
- **田里没水、或已经熟透时不消耗**，分别提示（"田里没水，肥也白搭" / "这株已然熟透"）。
- **骨粉已弱化**：成功率 0.8 → **0.35**，且只推进 1 档（书里没提骨粉；"凡禽獸骨"烧成的骨灰才算对症的药）。
  → 于是"粪肥/骨灰/烧土"这套才有存在意义。
- **粪肥的来源（闭环）**：碓出 **细糠**（书：以供犬豕之豢）→ 手持细糠右键**猪**或**狼**喂食 → 豕还**粪肥**（书：人畜穢遺）。
  同一头牲畜 1200 tick（约 1 分钟）冷却，冷却记在实体持久化数据里，**不需要 tick 钩子**。
  → 整条链：**种稻 → 打穗 → 舂米 → 糠喂猪 → 猪粪肥田 → 稻更好**。
- 新物品：`fen_fei` / `gu_hui` / `shi_hui`；配方（熔炉）：骨 → 骨灰（书：凡禽獸骨）、方解石 → 石灰。
- 生效判定写在 `RiceStalkBlock.useItemOn`（只有那一刻知道田底下的土），**没有动稻田方块的状态表**，旧存档安全。

### 3.9 水利收尾（桔槔／辘轳／风帆车 · 2026-09-20 落地）

书里水利节最后两句管这三件：「其淺池、小澮不載長車者……用**桔槔、轆轤**，功勞又甚細已」；
「揚郡以**風帆**數扇，**俟風轉車，風息則止**。此車為**救潦**，欲**去澤水以便栽種**。蓋**去水非取水也，不適濟旱**。」

| 方块 | id | 说明 |
|---|---|---|
| 桔槔 | `tiangongkaiwu:jie_gao` | 临水而立，**靠配重无人也自汲**，约 **16 秒**给邻田补 1 格田水——全套水利里最慢的一档 |
| 辘轳 | `tiangongkaiwu:lu_lu` | 同上，但**须有人立在 4 格内摇**（走开即停），约 **8 秒**一格；比桔槔快，仍远逊筒车 |
| 风帆车 | `tiangongkaiwu:feng_fan_che` | **只有下雨才转**；每约 3 秒**抽掉半径 5 内最近的一格水源**——就是书里的"去澤水以便栽種"；**不发动力、不给田补水、也不喂梘**（"去水非取水也，不適濟旱"落到机制上） |

- 三件都**不需要动力网**，单格、无自身方块实体（沿用 scheduleTick 局部规则），各带 4 帧动画（横杆翘／吊桶升降／四帆转）。
- **取水效率阶梯至此完整**：水桶（自己挑）→ **辘轳 8s／桔槔 16s**（浅池边，不必造动力网）→ 拔车（轴 1）／踏车（轴 4）／牛车（轴 9）→ 筒车（垒堰引激流，4 秒一格、昼夜不息）。
- **风帆车只抽"真正的水方块"且只抽水源**：水培稻那种含水方块不在内，所以放自家稻田边不会抽死禾苗；但**会抽干你挖的引水沟**——这就是"去水"，得离渠系远点放。
- 桔槔／辘轳登记进 `WaterDevices.isRunning`（所以能喂梘）；**风帆车故意不登记**。
- 配方（有序）：桔槔 = 木棍×3／绳／木板×3；辘轳 = 木板×5／木棍／绳；风帆车 = 木板×4／竹×4／绳。

**至此乃粒水利节的 8 组可验证知识全部落地**：①稻最依赖水 ②土性定保水 ③人力挽水 ④筒车 ⑤牛车／踏车 ⑥效率刻度（人5:牛10:短车2）⑦风帆车排水 ⑧桔槔辘轳最末。
