## 0. 设计总纲

> **书 = 玩法说明书，玩法 = 书的实验。** 解锁哪篇知识 → 能玩到哪套玩法；
> 书页讲的每一件事，游戏里都能亲手做、做了有回报。
> 现水稻（旱地版小麦形态）与书全面脱节 → **重做为两格水培稻**。

## 1. 稻作玩法闭环（玩家视角）

```
[获得种子] → [挖沟灌水造田] → [水面播种] → [秆长成] → [抽穗成熟]
    ↑                                                  ↓
[解锁稻事各篇] ← 翰墨台翻译 ← 拿残页 ← [收获稻谷] ← 打上部稻穗
                        ↘ 秆留着，再长新穗（再生）
```

- **造田**（稻工·水利）：离水源挖 1 格沟 → 灌静止水 → 水面插稻 → 必须临水
- **养田**（稻宜）：粪肥催熟（后续批）；骨灰蘸秧等小技巧
- **护田**（稻灾）：水格干涸 → 秆枯倒伏；成熟前断水减产
- **扩田**（水利·后续批）：筒车/踏车把水引离河远田，救活旱地

## 2. 书条目 ↔ 玩法机制 映射（全卷目标）

| 书条目 | 书页知识 | 机制落法 | 玩家验证动作 |
|---|---|---|---|
| 稻 | 稻在水中长、刈获 | **两格水培**：下部浸水秆 + 上部稻穗（成熟才有） | 造田、水面插稻、看它秆穗两段长出来 |
| **稻宜** | 粪田养地 | **粪肥体系**：骨粉对稻弱效/无效；粪肥催熟更强（后续批 #32） | 对稻用骨粉→没什么用；用粪肥→立见成效 |
| **稻工** | 灌溉造田、农时 | 造田=挖沟引水；**收穗留秆再生**=一种多收 | 打穗不毁秆，田越种越熟 |
| **稻灾** | 旬日失水则死 | **缺水即枯**：水格被抽干/断水 → 秆枯死 | 忘灌水=整片枯黄，长记性 |
| **水利** | 筒车/踏车引水 | **灌溉装置**：给远水田灌水（后续批 #33） | 造筒车 → 旱地也能开出稻田 |

## 3. 机制细化

### 3.1 水培稻方块（核心，参考农夫乐事 RiceBlock 结构）
- **单一方块两状态** 或 秆/穗两块组合？→ 技术实现定稿时选（倾向秆块 waterlogged + 上层穗块，成熟才有穗）。
- **种植**：手持种子对静止水源右键 → 水源格变"浸水稻秆"（waterlogged，仍含水），底部泥土/泥即可，**不要求耕地**。
- **生长**：秆块随机 tick 发育 → 成熟后在正上方长出稻穗块（两格高完整态）。
- **缺水死**：所在格水被取走/流走 → 秆枯（倒伏态）→ 不恢复则毁；枯死秆无收。
- **收获（再生）**：打上部稻穗 → 掉稻谷（+概率掉种子）；**秆保留**并重置"再长穗"计时；打秆 = 整株毁、少量回收（让玩家养成打穗习惯）。
- **canSurvive**：底部须是泥土系/泥/沙？（参考 FD 支持 dirt）——实现时定。

### 3.2 收获与加工（稻条目本体）
- 新物品 **稻谷**（穗上收获，不可直接吃）。
- 加工：稻谷 → 脱粒 → **米**（可食，小恢复）+ **稻种**（可再种，自留循环）。
- 脱粒方式：合成表（谷+手？）/ 简单工作台配方，初版用合成表最省。

### 3.3 种子来源与门控
- 种子 = 稻谷加工产物（自留）＋ 探索掉落起点（与残页同源 loot）。
- 配方/种植门控绑 unlock advancement（稻条目解锁后才给配方）；创造模式绕过。

### 3.4 粪肥 / 水利装置（后续批，稻核心稳后再上）
- #32 稻宜粪肥：粪肥物品（来源待定）+ 骨粉对稻弱化。
- #33 水利灌溉：筒车（放流水自动灌溉范围）/踏车等，"放置即灌水格"简化物理。

## 4. 与黍稷粟麻菽的关系

稻作机制定型 = 农书作物模板。每种新谷物 = 复制作物方块+种子+收获物+该条目门控；粪肥/灌溉等**通用机制共享**。

## 5. 明确不做（初版范围外）

- 品种细化（秔/稌/糯）、糯米酿酒 → 加工链期
- 牛力耕田、蝗灾事件
- 麦/黍稷粟麻菽作物本体（稻模板稳后复制）
- 水利物理模拟（先"放置即生效"）
