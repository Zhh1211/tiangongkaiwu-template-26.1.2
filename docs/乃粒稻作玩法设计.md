## 0. 设计总纲

> **书 = 玩法说明书，玩法 = 书的实验。** 解锁哪篇知识 → 能玩到哪套玩法；
> 书页讲的每一件事，游戏里都能亲手做、做了有回报。
> 现水稻（旱地版小麦形态）与书全面脱节 → **重做为两格水培稻**。

## 1. 稻作玩法闭环（玩家视角）

```
[首获 4 谷·解锁奖励] → [挖沟灌水造田] → [水面播种] → [秆长成] → [抽穗成熟]
    ↑                                                                  ↓
[解锁稻事各篇] ← 翰墨台翻译 ← 拿残页 ← [收获稻谷] ← 打上部稻穗
                          ↘ 秆留着，再长新穗（再生）
```

- **造田**（稻工·水利）：离水源挖 1 格沟 → 灌静止水 → 水面插稻 → 底部须为可作田的土（泥土系/泥/沙/砂砾/粗泥/黏土，**底材决定保水天数**），一格浅水
- **养田**（稻宜）：后续批 #34 舂米方块同时引入粪肥；骨粉对稻**暂时**有效，#32 后续弱化/无效化
- **管水**（稻灾 · 水利）：田水按底材蒸发，雨天/沟渠回充；见底水面退去、枯秆约旬日方死 → 倒水或等雨救活；空桶可主动取水
- **扩田**（水利 B 批 ✅）：**筒车**（3×3 大轮，流水自转）+ **梘**（引水槽）把水引到远田；配套**传动轴**构成动力网，为将来舂米等加工供能

## 2. 书条目 ↔ 玩法机制 映射

| 书条目 | 书页知识 | 机制落法 | 玩家验证动作 |
|---|---|---|---|
| 稻 | 稻在水中长、刈获 | **两格水培**：下部浸水稻秆 + 上部稻穗（成熟才有） | 造田、水面插稻、看它秆穗两段长出来 |
| **稻宜** | 粪田养地 | **粪肥体系**：骨粉对稻弱效/无效；粪肥催熟更强（后续批 #34 同批） | 后续：用骨粉→没什么用；用粪肥→立见成效 |
| **稻工** | 灌溉造田、农时 | 造田=挖沟引水；**收穗留秆再生**=一种多收 | 打穗不毁秆，田越种越熟 |
| **稻灾** | 旬日失水则死 | **缺水即枯**（水利 A 已落地）：田水按底材蒸发 → 见底 → 枯秆；枯秆约旬日方死 | 铺沙田看它三天就干；不浇水就枯黄；倒水或等雨救活 |
| **水利** | 稻独甚借水；筒车/踏车引水 | **A ✅**：底材定保水天数 + 雨/沟渠回充；**B ✅**：筒车（流水自转、栓木停机、动力 12）+ 梘（引水槽）+ 传动轴（动力网）；C 批：牛车/踏车/拔车/桔槔/风帆车 | A：沙田 vs 黏土田比干涸；B：垒堰 → 造筒车 → 梘引水到远田；轴通电后将来能带机器 |

## 3. 机制细化（v1 拍板定稿）

### 3.1 水培稻方块（核心，参考农夫乐事 RiceBlock 结构）

**两段结构**：
- **下部：`rice_stalk`（秆）**——waterlogged，AGE 0–7（沿用 `BlockStateProperties.AGE_7`）。
  - 种植：手持 `rice_grain` 对静止水源右键 → 水源格被替换为 `rice_stalk`（waterlogged=true、田水 moisture=7；底部须为可作田的土：泥土系/泥/沙/砂砾/粗泥/黏土）；上方必须空气。
  - 生长：随机 tick 仅在 `waterlogged=true` 时递增 AGE（约每 8 tick 一档）。AGE 满 7 时，若上方是空气 → 在其上方放置 `rice_panicle`（两格高完整态）。秆生长与抽穗概率可在实现时调。
  - 收获再生：打上部 `rice_panicle` → 秆（AGE 7）`setValue(AGE, 3)` → 秆可视地"缩回半截"再长回来；下次抽穗。
  - 打秆（打 `rice_stalk`）：**age==7 掉 1 粒保本**；未成熟（age<7）无掉落。秆毁时上方 `rice_panicle` 自动断裂正常掉粒（由 panicle 的 `neighborChanged` 触发）。
  - 通行：`noCollission()`，玩家/水流可穿过。
  - 骨粉：v1 暂接受骨粉催熟（performBonemeal +1..2 stage），#32 后续批再弱化/无效化。
- **上部：`rice_panicle`（穗）**——非水方块，仅作为成熟态视觉/收获入口。
  - 自毁条件：下方不是 `rice_stalk`（包括被掘、被舀空水后枯变等）→ 自毁带掉落。
  - 打穗：玩家破坏 → `playerWillDestroy` 把下方秆 AGE 重置为 3 → 秆复位后再生。稻谷由 `playerDestroy` **代码直弹**（2–3 粒 + 时运每级 +0~1），不走 loot table——破坏路径确定、与数据包加载解耦。秆毁穗断（neighborChanged）同样代码直弹。

**田水与枯死（水利 A · 2026-09-19 落地）**：
- **田水 = `rice_stalk` 新增 `moisture` 0–7**（满 = 刚灌过），随机 tick 结算：
  ① **下雨** → 不蒸发、缓缓回满（书：天澤不降，則人力挽水以濟 —— 反过来说降了雨就不必挑水）；
  ② **邻格有水**或邻格是带水的同类稻田（沟渠／连片水田）→ 缓缓回满；
  ③ 否则按**底材**概率蒸发：**沙≈3 天、砂砾/粗泥（磽）≈4 天、泥土/泥（泥）≈6–7 天、黏土（膩）≈半月**（书：厥土沙、泥、磽、膩，隨方不一，有三日即乾者，有半月後乾者）。
  数值集中在 `RiceStalkBlock` 顶部常量，随时可调。
- **田面见底**：moisture < 3 → 自动 `waterlogged=false`，水面可视地退去并**停止生长**（"该挑水了"的提示）。
- **干涸**：moisture 归零 → 转 `rice_stalk_dry`（**保 AGE**）；上方 `rice_panicle` 经 neighborChanged 自毁掉谷（已结的谷仍能收）。
- **干秆 `rice_stalk_dry`**：不生长、不抽穗；随机 tick 以 ≈1/176 概率枯死（约合书里"旬日失水则死"，留出抢救窗口），死时无掉落。
- **救活**：① 手持**水桶**右键干秆 → 复活为同 AGE 稻秆并灌满田水，同时返还空桶；② **下雨**时随机 tick 自动复活（同 AGE、田水满）。
- **主动取水**：手持**空桶**右键浸水稻秆 → 一次取走 3 格田水（取到见底则转枯秆），并给玩家水桶（创造模式只改状态不发桶）。
- **可作稻田的底土**（`canSurvive`）：泥土系 / 泥巴，外加书里点名的 **沙 / 砂砾 / 粗泥（磽）/ 黏土（膩）** —— 所以"沙田三天干、黏土半月干"玩家能自己铺出来验证。
- **Sponge 自然吸水路径**：与本批机制无关，留作海绵边界（玩家在创造里玩）。

### 3.2 物品链（命名已定稿 2026-09-07）

- **稻谷 `rice_grain`（Rice Grain）**：
  - 单一物品，兼**种子**（右键水面种植）和**脱粒原料**（合成入料）。不可食。
  - 名字/键：`item.tiangongkaiwu.rice_grain` → 稻谷 / 稻穀 / Rice Grain。
  - 贴图：沿用现 `rice_seed.png`（图标已是谷粒穗）。注册时删旧 `rice_seed`。
- **米 `rice`（Rice）**：
  - 脱粒产物，可食。**饱食 3 / 饱和度 0.4**（小恢复主食档）。未来熟饭升级链。
  - 名字/键：`item.tiangongkaiwu.rice` → 米 / 米 / Rice。
- **循环自洽**：收 2–3 粒 → 自留 1 粒种回 + 余下脱粒吃 → 净赚 ≥1 米、秆再生永不灭种。

### 3.3 脱粒与起点

- **脱粒**：v1 = **无序 1:1 配方**（`data/<ns>/recipe/thresh_rice.json`，`shapeless`，1 grain → 1 rice）。后续 #34 做舂米方块替换。
- **首获稻谷**：解锁「稻」条目（`tiangongkaiwu:unlock/naili_do`）时，**成就奖励掉落表**（`advancement.rewards.loot` 引用 `tiangongkaiwu:reward/unlock_naili_do`）给玩家 **4 粒稻谷**——保底开局。
- **门控方案**：**锁源头**——不写代码锁"种下去"或"合成"，种子只能靠解锁奖励入手（创造模式照常全可拿）。

### 3.5 水利装置（B 批 · 2026-09-19 落地）

**动力系统（模块化 · 机械动力的简化版）**：动力源 → 传动轴 → 加工机器（后续批）。

| 方块 | id | 作用 |
|---|---|---|
| 筒车 | `tiangongkaiwu:tong_che` | 3×3 大轮，**放一格自动展开、挖任意一格整台收回只掉一个**；车下须有**流水**方转（书：堰陂障流，激轮使转；静水不转）；空手右键**栓木**停机；输出**动力 12**，并给邻接的梘／稻田送水 |
| 梘 | `tiangongkaiwu:jian` | 定向输水：每格看**上游一格**（带水的梘／在转的筒车／一格水）→ 槽内积水，并约每 2 秒给挨着的稻田 +1 田水（枯秆也救活）。能把水**引过地形**、送到远处——挖沟做不到 |
| 传动轴 | `tiangongkaiwu:shaft` | 动力网：本格动力 = 邻格最大动力 **−1**（每格衰减 1，故有射程）；有动力时换铜箍贴图 |

- 动力数值**直接取自书里效率刻度**：筒车 **12**（昼夜不息，百畝無憂）／牛车 **10**（牛则倍之）／踏车 **5**（一人竟日五畝）／拔车 **2**（短车二畝而巳）。后三者属 C 批，接口已留好。
- 实现：`scheduleTick` 自调度 + 纯局部规则传播，**不需要方块实体**——这是本项目自动化的地基。
- 配方（**有序**）：传动轴 = 木棍／木板／木棍（得 4）；梘 = 竹＋木板（2×2，得 2）；筒车 = 木板×6 ＋ 绳×2 ＋ 竹×1（9 格，得 1）。
- 转动视觉：轮盘做成 4 帧**动画贴图**（16×64 竖条 + `.mcmeta`，游戏自动播放，零 tick 开销）；栓木后切静态贴图，肉眼可见地停住。
