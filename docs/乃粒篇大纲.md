## 4. 麦线设计提案（单条主线，麦工/麦灾并入页内）

- **种植**：旱地作物——走**原版耕地**（锄+播种），与稻的水培形成对照（书里稻麦分野正是水/旱）；生长 8 阶（贴原版小麦视觉但按田园风重画剪影）
- **水**：耕地湿度沿用原版机制即可，不接我们的田水系统（保持"旱地"身份；若要联动，湿度低长势慢即可）
- **轮作（书眼）**：「麦豆轮作」——机制**等地力系统 #40 一次做对**（2026-10-03 拍板：能等就等，不做注定返工的轻量占位）；书页文字照写，玩法后补
- **加工**：碓舂麦→**麦仁**（pounding 配方）；自创粒食见 §7
- **书页 3 页**：来牟名物（来=小麦牟=大麦）/ 荞麦"实非麦类" / 麦豆轮作之利

## 5. 杂粮线设计提案（3 条串行：黍稷粟→麻→菽）

### 黍稷粟 `shuji`
- **种植**：旱地耐旱——机制亮点：**不须人工灌溉**（种在普通耕地也长，只是慢；雨天加速），对应书"北方无水利，赖天时"
- **加工**：碓舂→**粟米**（小米）；自创：粟米粥
- **黍**（糯性）：标注"可酿酒"——**酿酒留给后续篇章**（书里酒在曲蘖/陶埏线），书页只提一句埋伏笔
- **书页 3 页**：黍粘稷不粘 / 粱粟=小米，北方主食 / 旱地农时

### 麻 `ma`
- **种植**：旱地；收获**麻秆**（纤维）+ **麻籽**（副产）
- **用途分层**：麻皮→搓**麻线**（乃服篇纺织的原料线头，此处只做"麻皮+碓舂→麻线"轻加工）；麻籽→可食（烤麻籽小食）+ 榨油留膏液篇
- **书页 3 页**：五谷之麻=火麻 / 胡麻（芝麻）西域传来 / 收子榨油入馔

### 菽 `shu`
- **种植**：旱地；**豆养地**（书眼）——机制同轮作，**等 #40 地力系统一次做对**（不做轻量占位）
- **加工**：碓舂菽→**豆瓣**；自创链：**豆浆**（豆瓣+水碗碓舂）→ **豆腐**（豆浆+营火熏凝，简化点卤；真卤水版留作咸篇彩蛋）
- **书页 3 页**：菽者众豆总名 / 豆饭豆油酱豉 / 豆养地力轮作

## 6. 加工产物的定位（对照原书结构）

- 原书把**磨面、榨油、做豆腐**等深加工放在《粹精》《膏液》——我们**不抢戏**：乃粒只做"**脱粒级**"加工（碓舂去壳出仁/米），深加工留后续篇
- 但用户拍板：**自创简单粒食可以进乃粒**（玩家种了一季总得马上有口吃的）——清单见 §7，全部只依赖现有机制（合成/碓/营火/食物组件），零新基建
