## 1. 章定位

《乃粒》= 全书第一谷部，讲"民以食为天"的粮食种植。玩家沿 **总论(引导·无锁) → 稻事支线 / 谷豆支线** 逐条解锁知识。

文言原文只活在翰墨台题面与题库里（内容数据、中文单语）；教程书正文 = **白话知识讲解**（三语），让"翻译成功"沉淀成真正读得懂的知识。

本章也为后续作物玩法铺路——水稻/麦/粟/豆/麻等作物方块落地时，知识背景直接挂钩本书条目。

### ① 总论 `zonglun`（已有 · 引导入口 · 无锁）
- **原书主题**：民以五谷为命 / 纨绔忘本之讽 / 五谷辨名（麻菽麦稷黍，独遗稻之故）/ 今稻居什七。
- **现状**：1 页。建议扩为 **3 页导读**：
  1. 谷为民生之命——开篇立意（"生人不能久生而五谷生之"，纨绔忘本之讽）
  2. 五谷辨名——麻菽麦稷黍何所指、"独遗稻"的西北缘由、今日稻居什七
  3. 本卷导读——这卷书讲什么、翰墨台怎么用、稻事与谷豆两大支线导览
- **题池**：已配 1 题（3 句）。
- **无锁**，无 unlock 文件。

### ④ 稻宜 `dao_yi`（新 · 父=稻）
- **原书主题**：稻之宜土 / 地力靠粪养 / 粪料诸品（人畜秽遗、榨油枯饼、草皮木叶）/ 冷浆土骨灰蘸秧根。
- **正文 3 页要点**：
  1. 土脉焦枯则穗实萧索——地力要人养
  2. 粪田诸品：人畜粪、油枯、草木灰草皮木叶，随方取用
  3. 因地制宜：冷浆田骨灰蘸秧根、视土性择肥
- **题域建议**（wenyan 从此段选短句）：粪田养地句、粪料列举句、土性宜忌句。

### ⑤ 稻工 `dao_gong`（新 · 父=稻）
- **原书主题**：收获即翻犁 / 耕-耙-耖三道序（牛力为主）/ 人力代牛（两人扛耜）/ 秧田（一亩秧供廿五亩）。
- **正文 3 页要点**：
  1. 刈获之后随手翻犁——冬土养地
  2. 治田之序：耕（起土）→ 耙（碎块）→ 耖（平泥），役牛之法
  3. 无牛之家人力代牛；秧田育秧与栽插
- **题域建议**：翻犁句、牛力句、秧田句。
- 残页串 `naili_juan/naili_dao_gong`，unlock `.../unlock/naili_dao_gong`；图标占位 `minecraft:wooden_hoe`。

### ⑥ 稻灾 `dao_zai`（新 · 父=稻）
- **原书主题**：旱最烈（旬日失水则死）/ 稻花遇风损实 / 湿种之患（育秧烂秧）/ 蝗灾。
- **正文 3 页要点**：
  1. 水是稻的命——旬日失水死期至，生长期耗水甚巨
  2. 稻花与风雨——花时逢风则谷虚，湿种水寒烂秧之防
  3. 蝗灾——旱后蝗生，人力驱捕
- **题域建议**：失水死期句（题库已有）、稻花句、湿种/蝗句。

### ⑧ 黍稷粟 `shuji`（新 · 父=总论）
- **原书主题**：黍稷同类（黍粘可酒、稷不粘）/ 粱粟同类（粟=小米，粱为粟之良者）/ 北方旱粮、春种秋成。
- **正文 3 页要点**：
  1. 黍与稷——粘者为黍可为酒，不粘为稷
  2. 粱与粟——同为小米系统，良莠之别、北方主食
  3. 旱地农时——北方无水利，赖天时，春播秋收
- **题域建议**：黍稷别句、粱粟句、北方时令句。

### ⑨ 麻 `ma`（新 · 父=总论）

- **正文 3 页要点**：
  1. 五谷中的"麻"——火麻（大麻），实与麻布用麻别为二物
  2. 胡麻即脂麻——张骞自大宛携来，今人呼芝麻
  3. 收子榨油——麻可粒可油，入馔入膏
