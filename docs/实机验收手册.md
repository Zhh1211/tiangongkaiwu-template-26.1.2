## 1 · 稻作闭环（种 → 收 → 舂 → 吃）

- [ ] **G1.1 全链**：锄地+挖坑放水插稻（四种土都行）→ 等熟 → 打穗得稻谷 ×2-3（秆留着再生）
- [ ] **G1.2 碓舂米**：踏车/牛车供劲 → 杆 → 碓；碓上方容器放稻谷、下方放箱子 → 出**米+细糠**；劲不足（拔车 2 劲）出**糙米**，糙米再舂出白米
- [ ] **G1.3 吃**：米 → 灶煮（或配方见 JEI）；稻谷放**营火**烤 → **爆稻花**（快食零食 1 点）
- [ ] **G1.4 田水**：放几天会干（沙最快黏土最慢）；见底停长、干透变枯秆；倒水/下雨救活且进度保留；空桶舀水一次只舀约 3 格并有「田水 N/7」提示

## 2 · 动力网

- [ ] **G2.1 杆沿轴传劲**：踏车→杆→碓能转；垂直贴一根杆 → 不通（变向必须牙轮/齿轮箱）
- [ ] **G2.2 杆自动成型**：连摆一串自动躺平接上；点端面顺着接
- [ ] **G2.3 牙轮 90° 变向**：横轴尽头放小牙轮 → 立杆上去能带碓；**直对直穿过牙轮不通**
- [ ] **G2.4 劲均摊**：一台踏车(5)带两台碓 → 全出糙米；拆一台 → 剩那台出白米；筒车(12)带三台 → 全白米
- [ ] **G2.5 杆显示**：通劲的杆**恒速旋转**（4.5s/圈）+ 负载率红色渐变（空网最红，吃满退木色）；同一网络所有杆一样亮
- [ ] **G2.6 齿轮箱**（格物解锁后）：六向全通（直通+变向都行）；横竖两版合成 1:1 互转

## 3 · 梘网与筒（连通器 · mB）

- [ ] **G3.1 无衰减找平**：长梘网一端灌水 → 各段水位渐平（Jade 看 mB），**不再逐格降级**；全网水量守恒
- [ ] **G3.2 灌田**：有水的梘贴稻田 → 漫灌拉满田水（1 点田水耗 250mB）；枯秆救活
- [ ] **G3.3 筒·泵**：低处梘网灌满 → 手持筒**右键山上梘段**装泵 → 泵段邻侧接轴 → 水顺劲上山（低段 −1B 高段 +1B）；空手右键拆下退筒
- [ ] **G3.4 筒·滑轮四模式**：筒独立放置空手右键循环——汲单/泻单/汲无限(<200 整抽)/泻无限(灌满空腔)；劲不足变慢
- [ ] **G3.5 隔板**：墨斗右键两根紧贴梘的贴合面 → 隔断各算各的；再点恢复（隔壁对侧同步）
- [ ] **G3.6 排涝造田（批4）**：涸田↔旱插——筒·滑轮「汲无限」抽干一小片池塘（≤200 格）→ 抽干格下是土的**沉降一格涸田**；手持稻谷**右键涸田顶面** → 旱插成功（无水也能种，田水 2/7 起步会蒸发）；挖涸田掉自身可搬用

## 4 · 水车与堰（本批新改，重点）

- [ ] **G4.1 堰陂障流**：① 静水塘放水车 → **不转**；② 车下挖一格河岸（单格流水）→ **仍不转**；③ 垒堰把河道收窄逼出 **≥2 格连续流水** → 转（恒速恒劲）；④ 拆堰 → 停转
- [ ] **G4.2 反馈**：转动时轮下偶有**水花粒子**；触静水不转时偶起**涟漪**（提示你去垒堰）
- [ ] **G4.3 栓木**：空手右键插栓停机（轮冻在当前角度，不跳回 0）、再右键复转
- [ ] **G4.4 整收整放**：挖大轮任意一格 → 只掉 1 个水车；物品落在挖的那格
- [ ] **G4.5 产劲**：转起来的水车 → 邻杆有劲（12 劲，能带三台碓全白米）

## 5 · 井具与墨斗拼装（本批新改，重点）

- [ ] **G5.1 桔槔**：临水放桔槔 → 上面摆 **1 根原木** → 墨斗右键核心 → 横杆消失、出现**真杆**（BER：杠杆绕支点摆、长端吊桶短端坠石）；有水即自己摆（约 16s 补 1 格田水，全套最慢）
- [ ] **G5.2 辘轳**：同样成型 → **绞轮+摇柄自转**；须人站 4 格内，走开轮停（约 8s 一格）
- [ ] **G5.3 拆线还原**：墨斗右键已成型的 → 机构方块退回原木、核心退回未成型；挖掉机构件或核心另一半也自动还原
- [ ] **G5.4 碓回归**：碓成型/拆线/自检照旧正常（墨斗泛化后碓不受影响）；碓杵仍是贴图动画（BER 杵位有设计冲突待议，见问题记录）
- [ ] **G5.5 墨斗其余**：扳手转杆轴；幽灵预览（白=木/黄=料口/红=轴/绿=换装件，随面向转）；缺件明细；潜行右键自动补料（创造不扣包）
- [ ] **G5.6 井具喂梘**：桔槔/辘轳旁边铺梘 → 能接到水（井具本职直喂）

## 6 · 肥田（粪田 v1）

- [ ] **G6.1 对症**：骨灰/石灰只宜**黏土田**（错土驳回不消耗+「向陽暖土不宜也」）；烧土（潜行+柴）只宜**砂砾/粗泥田**（错土「填墳鬆土不宜也」）；粪肥通用
- [ ] **G6.2 边界**：干田/熟透/错土都不扣物品；骨粉明显弱化（约 1/3 成功率 +1 档）
- [ ] **G6.3 细糠喂猪** → 粪肥（约 1 分钟冷却）
