## 2. D19 · 核心决策：梘 = 万能槽体，附件化

**一根梘，三种形态**（附件化架构，先例 = 批 3.5b 筒·泵形态右键梘段安装）：

| 形态 | 安装方式 | 职责 | 动力 |
|---|---|---|---|
| 空槽（默认） | 放置即成 | 走水（连通器，D16 规则不变） | 重力免费 |
| **龙骨段** | 手持龙骨右键梘段 | 动力段：刮板链定向搬运**水与物品** | 吃劲（劲传入方向=刮动方向） |
| 泵段 | 手持筒右键梘段（现有） | **只与世界交互**：汲世界源入网 / 泻网水回世界 | 吃劲 |

- 泵的「网内提水」职责（批 3.5b）**移交龙骨段**——泵收缩为纯世界接口。旧档泵迁移：保留汲泻功能，网内搬运提示改指龙骨。
- 梘从此不局限于运液体：无龙骨 = 水路，有龙骨 = 货路（也可刮水）。

## 3. 运动规则矩阵

| 场景 | 方案 | 动力 |
|---|---|---|
| 向下（斜段） | 物品因重力**自行下滑**（斜 45 足够陡）；水按 D7 自然下流 | 免费 |
| 水平 | 龙骨刮板推 | 吃劲 |
| 斜 45 度上坡 | 龙骨刮板（龙骨车本为斜置，物理成立）；无龙骨时物品自滑下行 | 吃劲 |
| 垂直井 | 绞盘筐串（二期，作咸卷绞缏） | 吃劲 |
| 零动力水平 | 水运：槽内梘网水 + 物品顺漂 | 免费（耗水） |

- **斜 45 度段**为新增梘朝向（斜置模型/碰撞，工程量中）。
- 放置交互对齐 Create：龙骨按「左点一下右点一下」沿梘铺装；方向 = 劲传入方向（对齐「筒方向=劲传入方向」既有规则）。

## 4. 龙骨刮板段细则

- 段内物品**不做 Entity**：采用 Create belt inventory 模式（方块实体持清单，渲染虚拟化）——Create 代码 MIT 可搬改留声明（写进鸣谢）。
- 刮水：龙骨段对网库存做**定向转移**（低段→高段，即原泵网内提水的接棒者）；连通器静力学（自动找平）与刮板动力学并存：无动力时维持 D16 连通器行为。
- 劲定额 + 档位不及则慢（D13 不变量：速度恒定，产量堆数量）。

## 5. 分期

1. **一期**：龙骨附件 + 斜 45 段 + 泵职责收缩 + 溜槽语义并入梘（斜段重力自滑免费）。
2. **二期**：绞盘筐串（垂直井，批量筐 3–5 × 8–16 件，劲档）。
3. **三期（远期）**：舟车火车——独轮车/漕舫实体、动物动力头（「骡马十二挂」=编组）、驿站站点、行程牌（时刻表）。

## 7. 分离：到站分拣（D20 候选，2026-10-17 查证）

核心：**古人的分离不在路上，在到站之后**——无黄铜漏斗式中途识别，分离靠设备。

| 设备 | 出处 | 分离原理 | 游戏映射 |
|---|---|---|---|
| 风扇车 | 粹精「风扇以去糠秕」 | 风力按轻重 | **一入两出分离器**（按物品分组，最常用） |
| 筛 | 粹精「谷未剖破者浮出筛面，重复入砻」 | 粒度 + 回路返工 | 一入两出（含退回重加工） |
| 水澄缸 | 陶埏「上浮者为细料…沉底者为粗料」、丹青朱砂同款 | 水中密度分级 | **一入三出**（多级分离） |
| 瓦溜 | 甘嗜「黄泥水淋」 | 过滤 | 特殊工艺设备 |

闭环：路上随便混（一段一物一液）→ 到站过风扇车/筛/澄缸 → 专仓专用（粮仓不收盐，古代仓储本态）。格物系统额度省下，无需开挂。

### 7.1 拣选盘（格物解锁 · 通用按类提取）

- 用户指正：§7 四设备全是**特定工艺专用**（作物/制陶/炼朱砂），通用「按类提取」超出古代工艺——古人通用的分拣只有**人手拣**（拣茶摊盘）与**纪律**（发货分装/专仓专用）。
- **提案（走格物路线，用户预设兜底）**：**拣选盘** = 格物巧思解锁的通用过滤器——挂在梘中途的独立段（或箱口），外观为摊开的拣选盘+竹夹；右键设置目标物品，链上货经过时**匹配的捡出**（落下方容器/侧溜槽），不匹配的继续走。
- 覆盖两个需求：梘中途按需捡取；混装箱单件提取。
- **液体无需分拣**：梘网一网一液（单 FluidStack），不同液天然不同网；出口按段类型分「水口/货口」即可。「混合液取某液」= 蒸馏/澄清，归膏液丹青工艺线。
- 玩法层次递进：发货端分装（最古代零设备）→ 到站工艺设备（扇车/筛/澄缸）→ 拣选盘（格物巧思，通用自动化）——与 mod 进度曲线同构。

开放问题余一条：拣选盘的「设置目标物品」界面形态（单物品 or 简单分组）——施工时定。

## 9. D19 补充拍板 3：转角（2026-10-17）

**转角 = 转向节点**：转角格同样装龙骨附件，自动识别两端开口方向（入向+出向），刮板链在格内 90° 转向——渲染画转向轮组（两小轮+弧线链，与牙轮变向同视觉语言），逻辑上物品数据入向传到出向，转角格照吃一份劲。

- 柔性链物理上本就能拐弯（对比：Create belt 不敢转弯只能端点对接）——刮板链白赚的优势。
- 无新机制：转角格 = 普通龙骨段 + 自动方向判定。

### 9.1 铺装算法（多弯网，2026-10-17 补）

1. **先点的端 = 链头（入口）**，后点的端 = 链尾；刮动方向从链头流向链尾（对齐 Create「先点即起点」直觉）。
2. 两端之间沿梘网图 **BFS 最短路**串链——拐几道弯都行，转角格自动成为转向节点。
3. 多条最短路并列（环路网）：确定性 tie-break（先直行后转弯优先序），同样的点击永远得到同一条链。
4. **分叉网**：一条链 = 一条简单路径；一个网可挂多条链（各支路独立铺装、各吃各劲、共享网库存）。
5. 已铺格拒绝复用（一条槽塞不下两条链）。
6. 玩家心智一句话：**点的不是路径，是两端；系统走最短路**。想要非最短路线就分段铺（点到中转弯、再点下一程）。

### 9.2 岔口闸板（2026-10-17 补，分叉/均分方案）

**龙骨不做均分**——一条链只走自己的路径（柔性链没有分身术），铺装决定走向。分叉的「分流/均分」由岔口附件负责：

- **岔口闸板**（梘第四种附件）：装在分叉格上，三模式——**直行**（默认）/ **改向**（全走支路）/ **交替**（一轮直行一轮转弯 = 自动均分）。
- **交替模式可调比例**：「对半分」「四六分」——致敬都江堰分水鱼嘴「四六分水」，古代分流比例控制的名场面。
- 渲染：岔口格一块可动闸板（开/关/半开），与梘隔板同族零件。
- 职责区分：闸板管**物品**转向；液体由连通器自动全网找平（已有梘隔板管液体隔离）——同族不同职。
- 组合玩法：岔口闸板 + 拣选盘 = 按物品种类自动分仓的完整流水线（闸板管路，拣选盘管货）。

### 9.3 岔口几何修订（2026-10-17，用户枚举验算后）

- **岔口几何只有三种**：进向除外，候选出路 = {前、左、右} 取二 → **左前 / 右前 / 左右**，无第四种（用户枚举验算通过）。
- **闸板模式按几何动态生成**：固定「直行/改向/交替」在「左右」岔口不成立（无直行）——模式 = 两条出路二选一 + 交替；左右岔口显示「左/右/交替」，左前显示「直行/左转/交替」，以此类推。
- **岔口格不放龙骨（用户修正）**：岔口格 = 纯闸板节点（有界缓存，约 1 组）。货流转 = 入段龙骨**段尾推入** → 岔口缓存 → 出段龙骨**段头吸入**；缓存满则入段停推（背压）。「段头吸入」为龙骨段基础能力（从容器进货同源）。
- **岔口格必须水平**：闸板是水平机构；斜 45 段只能作为岔口的出/入臂，不能作岔口格本体。
- **转角 ≠ 岔口**：L 形转角（2 口）= 普通龙骨段自动转向、照常放链；T 形岔口（3 口）= 闸板节点、不放链。视觉区分：转角链连续弯过，岔口链断开 + 闸板。


## 10. 端到端演练与细则定稿（2026-10-17，用户拍板「只允许水平岔口」后全链推演）

### 10.1 全流程（收割 → 入仓）

入网（段头吸入容器 / 手持右键塞入 QoL）→ 水平链（FIFO，一段一组一物，劲停货冻）→ 斜段重力自滑（免费）→ 转角链连续弯过 → 岔口（段尾推入缓存 → 闸板分配 → 出段段头吸入）→ 拣选盘中途捡取 → 绞盘竖井（二期）→ 到站段尾推入容器。

### 10.2 推演定稿的细则

1. **斜滑道连续性**：物品在连续斜滑道（含转角）内一路自滑到底，遇水平段/容器/缓存才停。
2. **交替遇背压**：闸板交替模式该轮目标路满 → 死等该路（保比例语义），上游缓存兜底，无死锁。
3. **拣选盘弹出去向**：下方容器 > 邻格段头 > 落地实体，不消失。
4. **货水同段共存**：一段 = 物品清单（≤1 组单物）+ 流体（网库存），互不干扰——刮板只推货，水只走连通器；视觉 = 货漂半槽水被刮板推。
5. **龙骨段两大基础能力**：段头吸入（容器/岔口缓存）+ 段尾推入（容器/岔口缓存），对称成对。
6. **背压全链统一**：任何缓存（岔口/段尾满/拣选盘出口）满 → 上游停推，无丢货路径。

### 10.3 推演结论

无死锁、无丢货路径；段头吸入/段尾推入对称、劲停货冻（D13 一致）、一网一液隔离液体分拣。设计闭环，待开工令。

## 11. 接口模型修订（2026-10-17，用户定）：龙骨段纯被动 + 悬袋

**作废**：§10.2 条 5「段头吸入/段尾推入」——龙骨段不再主动吸入/推出（用户指正：被动更简、更贴物理）。

### 11.1 龙骨段 = 纯被动通道

- 接受：手持右键塞入 / 掉落物落入 / 上游（刮板、岔口闸板、悬袋）推入。
- 段尾无承接 = **弹出掉落物**。
- 中途输入：任意段右键塞入（货排到该段尾部）。

### 11.2 悬袋（贴面小件，粹精卷背书；2026-10-17 v2 重做形态）

> 出处：粹精「悬袋磨上，上宽下窄，贮麦数斗于中，溜入磨眼」——古代喂料器本尊。

- **形态 v2（用户定）**：不做整格方块，做 **Create funnel 式贴面小件**——贴在容器/龙骨段的表面，一格可贴多面，不占空间。
- **吸/吐掉落物**：口朝上平时收集落在口上的掉落物漏给所贴容器；反向（吐模式）把容器/链里的货以掉落物弹出（发货卸货用）。
- **接入梘网 = 纯自动，无手动模式（用户 2026-10-17 纠正）**：贴在龙骨段上时看段的刮动方向——段尾朝向悬袋（货流向它）= **取出**（接货）；段头朝向悬袋（货背离它）= **喂入**（塞货）。同 Create 安山/黄铜漏斗对传送带的自动判定，墨斗不干预。墨斗对悬袋仅管一件事：贴容器用法下的**掉落物吸/吐模式**。
- **漏斗职能保留**：贴容器+贴链头之间 = 抽容器喂链（缓慢限速）；贴链尾+容器之间 = 接链尾弹出物漏进容器。
- 悬袋满（下口堵）→ 停吸停收（背压）。

### 11.5 悬袋行为补全（2026-10-17，用户指出水平终点死角）

纯「上承下漏」接不了**同高终点**（水平物流起点终点常同高）。修正：悬袋 = **漏斗形五面开口**（顶 + 四侧）——

- 任何面进来的货都收进袋；出口：正下方容器/链头（重力漏）→ 下堵则**塞侧面容器**（漏斗侧口行为）→ 全堵则袋内暂存（有界，满停收）。
- 链尾弹出物**带方向抛出 1–2 格**，飞进旁边悬袋侧口 → 同高终点闭环（箱子挨着悬袋即可，不必挖坑）。
- 「坚决不用原版漏斗」的边界 = 不用其**方块与视觉身份**；行为集（五面收集/下漏/下堵侧塞/抽上容器）由悬袋全盘继承，外观为布袋/木斗古代件。

### 11.3 岔口保留主动

岔口 = 阀门机构：闸板开启时把缓存货**推入**出路段头（人力开闸隐喻）。用户否的是龙骨主动，阀门主动保留。

### 11.4 主动权总表

| 部件 | 主动行为 |
|---|---|
| 龙骨段 | 无（纯被动通道） |
| 悬袋 | 缓慢抽上方容器（限速） |
| 岔口 | 闸板开启时推缓存出闸 |
| 绞盘（二期） | 筐串批量提升 |
| 拣选盘 | 弹出匹配物品 |

「泵物品」概念全程不存在：垂直=龙骨刮板（吃劲），其余全重力——与水系统哲学一致。
